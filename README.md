# serverstatus-shadcnui

[monitor](https://github.com/monitor-probe/monitor) 的一款公开页主题：沿用经典 ServerStatus 的表格与胶囊条布局，样式改为 shadcn/ui 风格，支持浅色、深色与跟随系统。基于 [monitor-theme-serverstatus](https://github.com/monitor-probe/monitor-theme-serverstatus) 修改。

![预览](preview.png)

## 安装

从 [Releases](https://github.com/tom2almighty/monitor-theme-serverstatus/releases) 下载
`theme.tar.gz`，在 hub 后台「主题」页上传，或解压到 hub 的 `--themes` 目录下的 `serverstatus-shadcnui/`。
之后可在同一页切换，卡片上的 ⟳ 从本仓库的最新 release 更新。
